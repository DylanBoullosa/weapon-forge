# Weapon Forge (C++)

Weapon Forge is a console-based C++ project where users design a custom weapon through a structured, multi-phase creation system.

The project focuses on practicing fundamental programming concepts such as conditionals, loops, input validation, and basic mathematical logic.

---

## Features

- Multi-phase weapon creation system
- User-driven design choices
- Input validation using loops
- Ability and modifier selection
- Simple performance simulation
- Final weapon summary and analysis

---

## Weapon Creation Phases

1. Weapon Category Selection  
2. Weapon Subtype Selection  
3. Power Level Assignment  
4. Ability Selection  
5. Modifier Application  
6. Test Simulation  
7. Weapon Performance Analysis  
8. Final Weapon Summary  

---

## Technologies Used

- C++
- Standard Library (`iostream`, `string`, `cmath`)
- Console-based input/output

---

## Purpose

This project was created to strengthen core C++ skills and demonstrate structured program design using incremental phases.

---

## How to Run

1. Compile the program using a C++ compiler
2. Run the executable
3. Follow on-screen prompts to create a custom weapon
